# 网站管理

`veydeck.websites` 用于在节点上部署静态网站和反向代理，支持 HTTPS、WebSocket、可选 IPv6 监听、证书管理及独立日志。

## 创建与管理网站

从应用库打开“网站管理”，填写名称、域名和端口，选择静态网站或反向代理。网站代号默认取首个域名，创建时可自定义，节点内必须唯一。

网站默认监听 `0.0.0.0`，可按需开启 IPv6。同一端口内域名不能重复，不同端口可复用域名；域名填写 `0.0.0.0` 可接收对应端口的所有请求。反向代理可指向节点本机或其他可达地址的服务端口。

创建、修改和启停网站时会检查 Nginx 配置并重载，无需额外发布。

## 网站目录

静态网站创建时自动生成 `index.html` 和 `404.html`，目录为：

```text
/opt/veydeck/data/www/websites/sites/<代号>/index/
```

点击网站列表或详情中的文件夹图标，可通过文件管理应用打开对应节点的目录。上传文件直接生效；上传目录后，可将其配置为相对运行目录，点击“保存并重载”生效。运行目录默认为 `index`，支持 SPA 回退。

## 证书

支持上传证书并解析域名、颁发组织、有效期等信息，也可使用本地根证书签发域名或 IP 证书。

每个实例独立生成内置根证书，也可创建自定义根证书。使用自签证书时，需下载根证书并在客户端添加信任。根私钥随套件数据持久保存，备份包含证书及私钥。

## 设置

- **性能**：调整 Nginx 全局请求头缓冲区、请求体大小、长连接超时、域名哈希桶和 gzip 参数；配置检查通过后保存并重载，检查失败保留原配置。
- **日志**：查看 Nginx 服务日志；各网站的访问和错误日志在对应网站详情中查看，分别保存。
- **备份**：备份套件配置、网站内容与证书数据。

## 运行与数据

套件运行管理服务与官方 Nginx 两个容器。管理服务重启时，Nginx 可继续提供已加载的网站服务。管理入口通过 Veydeck 代理访问，网站端口由 Nginx 在节点上监听。

数据保存在 `/opt/veydeck/data/www/websites`。卸载默认保留数据，再次安装时需显式接管保留数据。

套件使用 `services.control` 管理 Nginx 服务，通过 `operation-logs.write` 记录关键操作。Nginx 使用宿主机网络，安装前需确保配置的网站端口可用。
